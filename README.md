# 乌鸦面包店 · 互动绘本

给 Ada 的睡前故事：听《乌鸦面包店》，在关键处替小乌鸦一家做决定，
不同的选择会走到不同的画面和结局细节。家庭自用，非商用。
（故事灵感来自加古里子的经典绘本；插画由 AI 原创绘制，旁白为原创转述。）

## 玩法
- **选一只小伙伴**：小巧克力 / 小苹果 / 小柠檬 / 小年糕
  —— 它会一直陪着 Ada，旁白全程叫它的名字（每句都有 4 个配音版本）
- **4 个抉择改变剧情**：
  1. 烤焦的面包怎么办？（倒掉 / 给小乌鸦当点心）
  2. 先做什么形状的面包？（恐龙 / 飞机 / 企鹅）
  3. 客人排队太挤怎么办？（拿喇叭喊 / 分成两队）
  4. 最后一个面包送给谁？（消防员 / 爸爸妈妈 / 自己）
- 整页手绘插画 + 温柔女声旁白，点一下翻页，🔊 可重听，↩ 可回上一页

## 技术
- 纯静态 HTML/CSS/JS，无依赖；PWA + Service Worker（图片音频缓存优先，代码网络优先）
- 插画：Doubao Seedream，先出角色定妆图再作为参考图生成全部分镜，保证形象一致
- 旁白：edge-tts 晓晓，语速 -12% 适合幼儿；台词清单从 `js/story-data.js` 自动导出，避免文案走样

## 工具链
```bash
node tools/gen_scenes.mjs all        # 定妆图 + 20 张分镜插画
node tools/gen_companions.mjs        # 4 张小伙伴头像
node tools/build_voice_manifest.mjs  # 从故事脚本导出台词清单
python3 tools/gen_voice.py           # 批量生成旁白 MP3
```

## 本地试听
```bash
python3 -m http.server 8080   # 打开 http://localhost:8080
```
调试：`?node=n18` 可直接跳到某一页。
