# 乌鸦面包店 · 给 Ada 的烘焙经营小游戏

灵感来自加古里子的经典绘本《乌鸦面包店》（本项目为家庭自用的原创致敬作品：
美术与文字全部原创生成，不含绘本原插画/原文）。

## 玩法（v0.1）
- **做面包**：选模具 → 点面团揉一揉 → 烤炉里盯着火候，金黄一刻点"出炉！"
  - 烤焦了也不算失败：小伙伴们来把焦面包吃光，还送金币（呼应绘本核心转折）
- **开店啦**：客人排队，泡泡里显示想要的面包，从篮子里挑对递给它，数金币收钱
  - 卖到一定数量触发绘本名场面：大排长龙 + 消防车呜哇呜哇来看热闹
- **面包墙**：12 种造型面包图鉴，收集贴满一墙（致敬原著 87 种面包大跨页）
- 金币可以换新模具，逐步解锁全部 12 种造型

## 技术
- 纯静态 HTML/CSS/JS，无依赖；localStorage 存档；PWA + Service Worker 离线秒开
- 美术：Doubao Seedream 生成，1970 年代日式手绘绘本质感（水彩+彩铅+粗轮廓）
- 配音：edge-tts 预生成 MP3（晓晓旁白 + 晓伊小乌鸦），浏览器 TTS 仅兜底

## 工具链
```bash
node tools/batch.mjs all      # 批量生成美术素材（需 .env.local 的 Doubao key）
python3 tools/gen_voice.py    # 批量生成配音
```

## 本地试玩
```bash
python3 -m http.server 8080   # 打开 http://localhost:8080
```
