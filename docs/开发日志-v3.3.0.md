## 视频生成

脚本 `tools/gen_intro_video.mjs`：以 `assets/scenes/s01_tree.jpg` 为首帧做图生视频。
提示词 = 镜头缓缓推进穿过晨雾靠近大树面包店、阳光透过树叶洒下光斑、
树叶与藤蔓被微风吹动、几只小鸟飞过、烟囱飘出白色蒸汽、橱窗暖黄灯光渐亮。

**坑 1：图生视频不能传 `--ratio`**。输出比例由首帧决定，传了会失败：
`InvalidParameter.TaskTypeConstraint: For first-frame or first-last-frame generation,
the output ratio follows the first-frame`。去掉即成功。

**坑 2：原始产物是 1920x1080 HEVC，24.3MB**，对网页/iPad 都不合适
（HEVC 兼容性差、体积大）。用 ffmpeg 转码：

```bash
ffmpeg -i intro.mp4 -an -vf scale=1280:720 -c:v libx264 -profile:v main \
  -pix_fmt yuv420p -crf 27 -preset slow -movflags +faststart -y out.mp4
# 24.3MB → 0.95MB，画质无感知损失
```

## 接入方式

作为片头**第一个镜头**（5 秒），后面 4 个插画镜头、旁白、标题浮现全部不变。
`<video muted playsinline autoplay poster>`，并且 **`onerror` 自动回落**成原来的静态插画运镜，
即使视频加载失败片头也能照常播完，不会卡住。视频与海报图已加入 SW 预缓存清单。
